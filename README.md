# 🚰 Controle de Níveis de Água

Simulador em Python para monitoramento de níveis de água em reservatório pelo terminal. Utiliza a biblioteca Colorama para exibir alertas coloridos conforme o grau de risco (do nível 1 ao 5), aplicando conceitos de programação estruturada, funções e listas. Desenvolvido para atividade acadêmica de DSI.

## 🛠️ Tecnologias Utilizadas
- **Python 3**
- **Colorama**

## 🚀 Como Executar

1. Instale a biblioteca `colorama`:
```bash
python -m pip install colorama
